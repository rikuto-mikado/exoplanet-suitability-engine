# Exoplanet Suitability Engine

This project is a practice / experimental toy project created for learning purposes. The heuristic scoring model is simplified and designed for experimentation with astronomical datasets.

---

A lightweight Python tool that fetches data from the [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) and evaluates exoplanets based on simple habitability, orbital stability, and host star suitability metrics.

## Features

- **NASA TAP API Integration**: Fetches planetary and stellar parameters using ADQL queries.
- **Multi-factor Scoring**:
  - **Temperature & Climate** (`score_temp`): Evaluates equilibrium temperature and insolation flux.
  - **Rocky Composition** (`score_rocky`): Checks planetary radius, mass, and density.
  - **Orbit Stability** (`score_orbit`): Rewards circular, low-eccentricity orbits.
  - **Star Safety** (`score_star`): Assesses stellar effective temperature and system age.
  - **Observability** (`score_obs`): Considers distance from Earth for telescope observation feasibility.

## Quick Start

### 1. Install Dependencies

```bash
pip install requests pandas numpy
```

### 2. Fetch Data

Query the NASA Exoplanet Archive and save raw data to `data/planets.csv`:

```bash
python src/nasa_client.py
```

### 3. Run Scoring Engine

Calculate suitability scores and export results to `data/planets_scored.csv`:

```bash
python src/suitability.py
```
